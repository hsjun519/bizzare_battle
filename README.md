# BIZZARE BATTLE — 철학 vs 자본

철학자 4명과 자본가 4명이 맞붙는 브라우저 아케이드 대전 격투 게임입니다.
설치나 빌드 없이 브라우저에서 바로 실행됩니다. 그래픽, 애니메이션, 효과음, 배경음악을 모두 코드로 실시간 생성합니다.

> **이 게임만의 시그니처**
>
> 1. **논파·인수 (REFUTE & ACQUIRE)**: 상대의 기술을 받아치는 순간 그 기술을 **빼앗아 내 것으로 씁니다.**
> 2. **패러다임 시프트 (PARADIGM SHIFT)**: 라운드 도중 **세계의 법칙 자체가 바뀝니다.**

---

## 시그니처 ① 논파·인수: 상대의 기술을 빼앗는 격투

상대가 필살 기술(`기술` 버튼으로 나가는 기술)을 쓰면, 맞기 직전에 **뒤 방향을 새로 탭**합니다. 그러면 저스트 가드가 발동합니다.

- 철학자는 **"논파!"**, 자본가는 **"인수!"** 를 외칩니다. 칩 데미지가 없고, 경직이 짧고, 게이지를 얻습니다.
- 막은 공격이 필살 기술이었다면 **그 기술을 10초 동안 빼앗습니다.** `↑ + 기술`로 **내 캐릭터가 상대의 기술을 씁니다.**
  예: 소크라테스가 젠슨 황의 GPU 칩을 던지고, 니체가 버핏의 복리 코인을 굴립니다.
- 빼앗긴 쪽은 그 기술이 **잠깁니다**(HUD에 🔒 표시). 도둑이 그 기술을 쓰거나 10초가 지나야 돌아옵니다.
- 그래서 필살 기술을 함부로 내밀 수 없는 심리전이 생깁니다. 반대로 상대가 기술을 노리고 있을 때는 페이크가 통합니다.

## 시그니처 ② 패러다임 시프트: 라운드마다 바뀌는 세계의 법칙

라운드 시작 15초 뒤에 철학·경제 **법칙 카드**가 뒤집힙니다. 남은 라운드 동안 양쪽에 똑같이 적용되고, 매 라운드 다른 카드가 나옵니다.

| 법칙 | 효과 |
| --- | --- |
| 영원회귀 | 6초마다 두 사람이 **3초 전의 자리로 되감깁니다.** 체력은 돌아오지 않습니다. |
| 동굴의 비유 | 화면이 어두워지고 **실루엣과 벽에 비친 그림자로만** 싸웁니다. |
| 보이지 않는 손 | 모든 투사체가 상대를 향해 **유도**됩니다. |
| 반중력 이론 | 중력이 60%로 줄어 공중 콤보가 길어집니다. |
| 인플레이션 | 모든 데미지가 +35% 오릅니다. |
| AI 호황 | 필살기 게이지가 3배 빨리 찹니다. |
| 제로섬 게임 | 준 데미지의 35%만큼 체력을 회복합니다. |
| 빅 아이디어 | 머리가 커지고 모든 공격 판정이 25% 커집니다. |

설정에서 끌 수 있고, 트레이닝 모드의 일시정지 메뉴에서 원하는 법칙을 직접 시험할 수 있습니다.

## 캐릭터

| 진영 | 캐릭터 | 기술 / →기술 / ↓기술 | 필살기 | 특성 |
| --- | --- | --- | --- | --- |
| 철학 | **소크라테스** | 질문 공세 / 논박술 연타 / 아테네의 등에(유도) | 산파술: 끝없는 문답 (잡기 연출) | 맞을수록 게이지 2배 |
| 철학 | **플라톤** | 이데아 큐브 / 동굴의 그림자 이동(순간이동) / 철인의 기둥 | 이데아계 강림 (정다면체 5종) | 투사체 관통 |
| 철학 | **니체** | 망치로 철학하기(중단+충격파) / 힘에의 의지(아머 돌진) / 디오니소스의 춤 | 위버멘쉬 각성 (10초 강화) | 체력 30% 이하 공격력 +20% |
| 철학 | **디오게네스** | 정직한 인간 탐색(등불) / 통 굴리기 / 충견 출동 | 보라, 플라톤의 인간이다! (닭 폭격) | 앉으면 통 속에서 투사체 무시 |
| 자본 | **젠슨 황** | 텐서 코어 칩 / 가죽 재킷 토네이도 / 쿨링 팬 어퍼컷 | 레이 트레이싱: 풀 패스 (화면 관통 빔) | 체력 50% 이하 재킷 탈의, 속도 +12% |
| 자본 | **일론 머스크** | 도지 코인 / 보링 컴퍼니 드릴(땅속 이동) / 팰컨 착륙 | 스타십 발사 | 게이지 획득 +25% |
| 자본 | **워런 버핏** | 복리 코인(날수록 커짐) / 체리 콜라 샤워 / 가치 투자(받아치기) | 월가의 황소 | 콤보 데미지 감소 완화 |
| 자본 | **애덤 스미스** | 보이지 않는 손(원거리 잡기) / 핀 공장의 분업 / 수요와 공급의 교차 | 국부론 (1776) 낙하 | 지고 있으면 게이지 자동 충전 |

모든 캐릭터는 공통 기본기(약·강·→강 중단·↓약 하단·↓강 띄우기·공중 약/강·잡기)를 가집니다.

## 시스템

- **콤보와 캔슬**: 약 → 약 → 강 → 기술처럼 이어지고, 맞히면 기술·필살기로 캔슬됩니다. 히트 수에 따라 데미지가 보정됩니다.
- **띄우기와 공중 콤보**: `↓+강`이 맞는 순간 `↑`를 누르면 하이 점프로 추격합니다.
- **가드**: 뒤로 누르면 가드됩니다. 하단은 앉아서, 점프 공격과 `→+강` 내려찍기는 서서 막아야 합니다.
- **잡기**: `약+강` 또는 잡기 키로 가드를 무시합니다. 잡힌 직후 `약+강`을 누르면 풀어냅니다(TECH).
- **대시 / 백대시**: 앞 앞, 뒤 뒤. 백대시는 순간 무적입니다.
- **카운터, 히트스톱, 화면 흔들림, 슬로모션 K.O., 필살기 컷인**으로 타격감을 연출합니다.

## 모드

- **아케이드**: 6연전을 치르고 마지막에 숙명의 라이벌과 싸웁니다. 클리어하면 캐릭터별 엔딩이 나오고 점수가 기록됩니다.
- **VS CPU**: 상대, 스테이지, 난이도(쉬움·보통·어려움·철인)를 고릅니다.
- **2P 대전**: 키보드 하나 또는 게임패드 두 개로 대전합니다.
- **트레이닝**: 더미 행동, 판정 박스 표시, 게이지 무한, 법칙 시험, 프레임 정보를 지원합니다.
- **플레이 가이드**: 조작, 시스템, 시그니처, 법칙 도감, 캐릭터별 기술표를 안내합니다.

스테이지 5종: 아테네 아고라 · 월스트리트 · 화성행 발사장 · 플라톤의 동굴 · GPU 데이터센터. 스테이지마다 배경음악이 다릅니다.

## 조작

| | 1인 플레이 | 2P 대전 · 1P | 2P 대전 · 2P |
| --- | --- | --- | --- |
| 이동 / 점프 / 앉기 | WASD 또는 방향키 | WASD | 방향키 |
| 약 / 강 | J / K (또는 Z / X) | F / G | `,` / `.` (넘패드 1 / 2) |
| 기술 / 필살기 | L / I (또는 C / V) | H / T | `/` / `;` (넘패드 3 / 5) |
| 잡기 | U (또는 B, 약+강) | R | `'` (넘패드 4) |
| 빼앗은 기술 | ↑ + 기술 | ↑ + H | ↑ + `/` |
| 일시정지 | Esc / P | Esc | Esc |

- **게임패드**: X 약 · Y 강 · B 기술 · RB/RT 필살 · LB/LT 잡기 · A 점프 · Start 일시정지
- **터치**: 화면 왼쪽을 누르면 스틱이 생기고, 오른쪽에 버튼이 있습니다. 빼앗은 기술이 있으면 `인수` 버튼이 나타납니다.
- `M` 키로 소리를 켜고 끕니다.

## 실행

Node.js 20 이상이 필요하고 외부 패키지는 쓰지 않습니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 정적 파일만 있으므로 어떤 정적 호스팅에도 올릴 수 있습니다.

### GitHub Pages

저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, 브랜치를 `main`, 폴더를 `/ (root)`로 지정합니다. `.nojekyll`이 들어 있어 파일이 그대로 게시됩니다.

## 개발

```sh
npm run check     # 모든 소스 문법 검사
npm test          # 엔진·시그니처 시스템 테스트 + 전 매치업 CPU 대전 시뮬레이션
npm run balance   # CPU vs CPU 리그전 통계 (승률, 기술 사용량, 논파 횟수)
```

- `tests/mechanics.test.mjs`: 가드 상·중·하단, 잡기와 풀기, 띄우기 캔슬, 논파·인수와 기술 잠금, 패러다임 8종, 전 캐릭터 기술 발동을 검사합니다.
- `tests/sim.test.mjs`: 8×8 모든 매치업을 CPU끼리 끝까지 싸우게 하고, 결정론적 재현성을 확인합니다.
- 주소 뒤에 `#lab`을 붙이면 캐릭터 포즈 갤러리가, `#fight:plato:huang:cave:training`처럼 붙이면 해당 대전이 바로 열립니다.

### 구조

```
src/
  main.js            부팅, 고정 60Hz 루프, 화면 스케일
  core/              입력(키보드·게임패드·터치), Web Audio 합성기와 작곡 데이터, 저장
  game/              전투 엔진(battle, fighter), 기본기, 패러다임, CPU AI
  chars/             캐릭터 8명: 외형 페인터 + 기술 데이터 + 투사체 연출
  render/            골격 리그(IK), 공통 애니메이션, 스테이지, 이펙트, HUD, UI
  scenes/            타이틀, 선택, VS, 전투, 결과, 엔딩, 가이드, 설정
```

캐릭터는 공통 2D 골격 리그 위에 그려집니다. 손발 목표 위치를 IK로 풀고, 캐릭터마다 머리·의상·소품 페인터를 얹습니다. 기술 데이터(프레임, 판정 박스, 데미지)와 애니메이션 키프레임이 한 파일에 들어 있어 새 캐릭터를 추가하기 쉽습니다.
