# Bizzare Battle

철학과 자본의 한판 승부. 젠슨 황, 일론 머스크, 소크라테스, 플라톤, 니체, 워런 버핏이 등장하는 오리지널 픽셀 아트 브라우저 대전 게임입니다.

## v2 — The Rulebreakers

캐릭터마다 **일반 기술 2개, 필살기 1개, 특성 1개**가 있습니다. 기술은 경기장에 물체를 남기며 양쪽이 발판으로 사용하고, 밀고, 부수고, 회수하고, 인수할 수 있습니다.

| 캐릭터      | Q / E                                           | L 필살기                                   | 특성                                                                  |
| ----------- | ----------------------------------------------- | ------------------------------------------ | --------------------------------------------------------------------- |
| 젠슨 황     | NVDA 캔들 매수·매도 / 수정 가능한 콤보 프로그램 | 액면분할로 칩 발판 생성·병렬 발사          | 재킷 방어막 22, 파괴 후 티셔츠·이동 +18%, 바닥에 남은 재킷에 미끄러짐 |
| 일론 머스크 | TSLA 목표가 예약 발사 / 순환·중력·반사 패치     | 탑승 가능한 SpaceX 스타십                  | 부스터를 소모하고 R로 회수해야 재사용                                 |
| 소크라테스  | 질문 발사·돌 / 발사 조건·지분의 전제 추출       | 발사체 점프·저장하는 벽·실체화된 그림자    | 강한 피격에 질문 돌, 정의 스위치를 깨면 규칙 종료                     |
| 플라톤      | 조명 / 원본·사본 결정 설계                      | 그림자가 실제 피격 대상이 되는 동굴의 비유 | 원본을 밀면 사본도 이동, 원본 파괴 시 사본 비활성화                   |
| 니체        | 돌파 / 영원회귀                                 | 매도·자발적 철거를 금지하는 아모르 파티    | 체력 50 이하 코트 파괴, 가장 최근 공격을 반복                         |
| 워런 버핏   | 지분 인수 / 발사체 경매                         | 캐릭터·시설·가방을 운반하는 BNSF 열차      | 서류가방 가까이에서만 시설 명령 가능                                  |

### 상호작용

- **R:** 근처 부스터·가방 회수, 조명 회전, 논점 조작, 경매 입찰, 시설 지분 매수. 가까운 대상이 없으면 주식 매수.
- **S+R:** 매도. 예약 발사대가 있으면 양쪽 모두 TSLA에 거래할 수 있습니다. 매수 +6, 매도 -6이며 시장 자체도 천천히 변합니다.
- 전투 화면의 NVDA·TSLA·BRK.B 옆 **+ / −** 버튼으로 종목을 직접 매수·매도할 수도 있습니다. 버핏도 가방을 들고 주식 거래가 가능합니다.
- 매수는 12 자본, 매도는 9 자본 반환. 지분 34%는 20 자본, 입찰은 8 자본. 보유 주식·자본 부족과 매도 금지 규칙을 적용합니다.
- 지분 과반을 확보하면 시설 소유권이 이전됩니다. 소유권을 되사는 것도 가능합니다.
- 펀치·킥으로 시설을 밀거나 파괴하고 프로그램 방향을 바꿉니다. 이동 방향을 누르면서 공격하면 그 방향을 겨냥할 수 있습니다.
- 원본은 금빛 테두리, 사본은 연결선, 그림자 피격 위치는 점선, 과거 공격은 붉은 예고선으로 표시합니다.
- 영원회귀와 반사된 공격은 발사자에게도 피해를 줍니다. 체력은 되감기지 않습니다.
- 규칙 변경에는 예고가 있고 양쪽에 동일하게 적용되며 동시에 최대 3개만 활성화됩니다.
- **실험실:** 상대는 움직이지 않고 필살기는 빠르게 충전됩니다. 훈련 초기화 버튼·체력 소진·시간 종료로 장비와 물체를 복원합니다.
- **발견 도감:** 실제로 일으킨 상호작용 10종을 로컬에 기록합니다.
- **승부 영수증:** 피해·방어·방어막·적중·헛침·기술·인수·거래를 집계하고 경기 후 PNG로 저장합니다.

시세·계약·대사는 게임을 위한 창작입니다. 그래픽과 효과음은 로컬에서 생성하며 별도 금융 API가 필요하지 않습니다.

## 실행

Node.js 20 이상에서 실행합니다. 외부 패키지나 API 키가 필요하지 않습니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. `PORT=8080 npm run dev`로 포트를 변경할 수 있습니다. 서버는 기본적으로 `0.0.0.0`에 바인딩되며, 필요하면 `HOST=127.0.0.1`을 지정합니다.

## 게임

- 6명의 캐릭터와 고유 능력, 3개의 경기장, CPU 난이도 3단계
- CPU 대전 및 같은 키보드에서 2인 대전
- 60초 라운드, 2라운드 선승. 타임아웃은 남은 체력으로 결정하며 무승부는 점수 없이 다음 라운드로 진행
- 펀치·킥·점프·앉기·전방 방어 및 충전식 필살기
- 소리 켜기/끄기, 일시정지, 자동 포커스 일시정지, 재대전, 캐릭터 선택 복귀
- 터치 기기의 1인 대전 조작 버튼, 키보드 선택, 설정의 로컬 저장

| 조작        | 플레이어 1 | 플레이어 2   |
| ----------- | ---------- | ------------ |
| 이동        | A / D      | ← / →        |
| 점프 / 앉기 | W / S      | ↑ / ↓        |
| 펀치 / 킥   | J / K      | 1 / 2        |
| 필살기      | L          | 3            |
| 기술 1 / 2  | Q / E      | 4 / 5        |
| 조작 / 매도 | R / S+R    | 6 / ↓+6      |
| 방어        | 왼쪽 Shift | 오른쪽 Shift |
| 일시정지    | Esc        | Esc          |

필살기 게이지는 공격, 피격, 시간 경과로 충전됩니다. 게이지가 가득 차면 필살기를 사용할 수 있습니다. 공격 버튼을 누르고 있으면 쿨다운에 맞춰 반복 공격합니다. 2인 모드는 키보드가 필요하며, 일부 키보드는 동시에 많은 키를 누를 때 입력 수에 제한이 있습니다.

## 검증

```sh
npm run check
npm test
```

`tests/engine.test.mjs`는 필살기 6종, 공격 거리·쿨다운, 방어, 점프 회피, 일시정지, 시간 종료·승패·라운드 리셋, CPU 행동을 검증합니다. `tests/browser_smoke.py`는 Playwright가 설치된 환경에서 실제 Chromium으로 UI·입력·모바일을 검증합니다.

`tests/world.test.mjs`는 재킷·부스터·지분·경매·그림자 판정·원본 연결·영원회귀·가방·열차를 검증합니다. 전체 테스트에는 6×6 캐릭터 조합의 혼합 입력 시뮬레이션도 포함되어 있습니다. 브라우저 검사는 여섯 캐릭터의 Q/E/L, 특성 안내, 규칙 표시, 영수증 다운로드, 2인 입력, 실험실 초기화와 모바일을 확인합니다.

```sh
# 서버를 실행한 상태에서
python3 tests/browser_smoke.py
```

## 구성

- `src/engine.js`: DOM과 분리된 전투·AI·라운드 로직
- `src/world.js`: 물체·가상 주식·규칙·인수·경매·공격 기록과 재생
- `src/art.js`: Canvas로 직접 그린 캐릭터·경기장·공격 효과
- `src/roster.js`: 캐릭터별 능력과 설정
- `src/main.js`: 선택 화면, 입력, 게임 진행, Web Audio
- `scripts/server.mjs`: 외부 의존성 없는 정적 개발 서버

현대 브라우저의 ES modules, Canvas 2D, Web Audio를 사용합니다. 인터넷 연결 없이도 모든 그래픽과 게임 기능을 사용할 수 있습니다. 정적 파일만 호스팅하면 배포할 수 있으며, `index.html`, `favicon.svg`, `src/`를 함께 제공합니다.
