# Bizzare Battle

철학과 자본의 한판 승부. 젠슨 황, 일론 머스크, 소크라테스, 플라톤, 니체, 워런 버핏이 등장하는 오리지널 픽셀 아트 브라우저 대전 게임입니다.

## GitHub Pages 게시

저장소의 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 저장합니다. 배포가 완료되면 다음 주소로 플레이할 수 있습니다.

https://hsjun519.github.io/bizzare_battle/

`.nojekyll`이 포함되어 있어 게임의 정적 파일이 변환 없이 게시됩니다. 별도 빌드나 서버는 필요하지 않습니다. 처음 게시하거나 파일을 변경한 후에는 GitHub Pages 배포가 완료될 때까지 잠시 기다려야 합니다.

## 실행

Node.js 20 이상에서 실행합니다. 외부 패키지나 API 키가 필요하지 않습니다.

```sh
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. `PORT=8080 npm run dev`로 포트를 변경할 수 있습니다. 서버는 기본적으로 `0.0.0.0`에 바인딩되며, 필요하면 `HOST=127.0.0.1`을 지정합니다.

## 게임

- 6명의 캐릭터와 고유 능력, 3개의 경기장, CPU 난이도 3단계
- CPU 대전 및 같은 키보드에서 2인 대전
- 60초 라운드, 2라운드 선승. 타임아웃은 남은 체력으로 결정하며 무승부는 점수 없이 다음 라운드로 진행
- 펀치·킥·점프·앉기·전방 방어 및 충전식 필살기
- 소리 켜기/끄기, 일시정지, 자동 포커스 일시정지, 재대전, 캐릭터 선택 복귀
- 터치 기기의 1인 대전 조작 버튼, 키보드 선택, 설정의 로컬 저장

| 조작 | 플레이어 1 | 플레이어 2 |
| --- | --- | --- |
| 이동 | A / D | ← / → |
| 점프 / 앉기 | W / S | ↑ / ↓ |
| 펀치 / 킥 | J / K | 1 / 2 |
| 필살기 | L | 3 |
| 방어 | 왼쪽 Shift | 오른쪽 Shift |
| 일시정지 | Esc | Esc |

필살기 게이지는 공격, 피격, 시간 경과로 충전됩니다. 게이지가 가득 차면 필살기를 사용할 수 있습니다. 공격 버튼을 누르고 있으면 쿨다운에 맞춰 반복 공격합니다. 2인 모드는 키보드가 필요하며, 일부 키보드는 동시에 많은 키를 누를 때 입력 수에 제한이 있습니다.

## 검증

```sh
npm run check
npm test
```

`tests/engine.test.mjs`는 필살기 6종, 공격 거리·쿨다운, 방어, 점프 회피, 일시정지, 시간 종료·승패·라운드 리셋, CPU 행동을 검증합니다. `tests/browser_smoke.py`는 Playwright가 설치된 환경에서 실제 Chromium으로 UI·입력·모바일을 검증합니다.

```sh
# 서버를 실행한 상태에서
python3 tests/browser_smoke.py
```

## 구성

- `src/engine.js`: DOM과 분리된 전투·AI·라운드 로직
- `src/art.js`: Canvas로 직접 그린 캐릭터·경기장·공격 효과
- `src/roster.js`: 캐릭터별 능력과 설정
- `src/main.js`: 선택 화면, 입력, 게임 진행, Web Audio
- `scripts/server.mjs`: 외부 의존성 없는 정적 개발 서버

현대 브라우저의 ES modules, Canvas 2D, Web Audio를 사용합니다. 인터넷 연결 없이도 모든 그래픽과 게임 기능을 사용할 수 있습니다. 정적 파일만 호스팅하면 배포할 수 있으며, `index.html`, `favicon.svg`, `src/`를 함께 제공합니다.
